Pipeline de Procesamiento de Datos

El proyecto busca automatizar el procesamiento de datos, reduciendo tareas manuales de limpieza, transformación y validación, para utilizarlos de manera más eficiente tras el proceso y no encontrar valores incorrectos o nulos. El objetivo es mejorar la eficiencia del procesamiento y limpieza de datos,facilitando su posterior análisis y utilización.

¿Qué problema resuelve?

El proyecto resuelve el problema de la gestión y procesamiento de grandes volúmenes de datos, permitiendo a los usuarios automatizar tareas de limpieza, transformación y análisis de datos.

¿Qué hice?

En este proyecto participé en el desarrollo del pipeline utilizando Python y bibliotecas como NumPy y scikit-learn. Implementé procesos de limpieza, transformación y validación de datos, utilizando archivos de datos como fuente de entrada y Docker para la ejecución del proyecto

¿Qué aprendí?

Aprendí a trabajar con datos utilizando bibliotecas de Python y a implementar un pipeline para automatizar procesos de limpieza, transformación y validación. Además, aprendí a entrenar modelos de Machine Learning para realizar predicciones y evaluar su rendimiento mediante métricas como Accuracy, Precision, Recall y F1-Score.
