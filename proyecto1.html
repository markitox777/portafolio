Proyecto EcoMarket

EcoMarket es un proyecto de e-commerce sostenible desarrollado durante mi formación académica.

Su objetivo es facilitar el acceso a productos ecológicos y sostenibles mediante una plataforma digital.

Tecnologías utilizadas:

Python, Django, SQL, HTML, CSS.

¿Qué problema resuelve?

El proyecto resuelve el problema de la falta de acceso a productos ecológicos y sostenibles en el mercado digital, permitiendo a la gente descubrir y comprar estos productos para consumidores conscientes del impacto ambiental.

¿Qué hice?

En este proyecto, participé en el desarrollo del backend utilizando Python y Django, implementando la base de datos con SQL y diseñando la interfaz de usuario con HTML y CSS. También contribuí a la optimización del rendimiento.

¿Qué aprendí?

Aprendí a trabajar con tecnologías web modernas, a resolver problemas de manera eficiente y a colaborar en un entorno de desarrollo ágil con mis compañeros mediante Git.
